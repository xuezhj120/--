# 校园生活卡牌交互模块

**日期**: 2026-08-05  
**状态**: 已确认

## 概述

将校园生活模块（#module-market）替换为全屏卡牌交互系统。用户通过 1 张中心主卡牌 + 4 张子卡牌的方式探索内容。

## 架构

```
module-market (全屏容器, 100vh)
├── .card-bg-layer           背景层 (assets/IMG_4275.JPG + 暗色遮罩 overlay)
├── .card-stage              卡牌舞台 (相对定位，居中区域)
│   ├── .main-card           主卡牌 "Campus Life" (280x360px, z-index 最高)
│   ├── .sub-card.dorm       子卡牌 "宿舍" (左上方向)
│   ├── .sub-card.canteen    子卡牌 "食堂" (右上方向)
│   ├── .sub-card.sports     子卡牌 "运动" (左下方向)
│   └── .sub-card.shops      子卡牌 "商铺" (右下方向)
└── .card-detail-overlay     全屏详情层 (fixed, 初始隐藏)
    ├── .card-detail-content  内容区域
    ├── .card-detail-close    × 关闭按钮
    └── .card-detail-body     各卡牌对应内容
```

## 交互状态机

### 状态 1：初始 (idle)
- 主卡牌居中，轻微悬浮动画（上下浮动 translateY）
- 4 张子卡牌隐藏在主卡牌后方 (opacity:0, scale:0.5, 位置与主卡牌重叠)
- 背景展示校园图片 + 半透明暗色遮罩

### 状态 2：展开 (expanded)
- 触发：点击主卡牌
- 主卡牌轻微上移 (translateY: -30px)，scale: 0.95
- 4 张子卡牌从当前位置沿对角线方向滑出到各自位置：
  - 宿舍 → 左上 (-140px, -180px)
  - 食堂 → 右上 (+140px, -180px)
  - 运动 → 左下 (-140px, +180px)
  - 商铺 → 右下 (+140px, +180px)
- 每张卡牌出现有 50-100ms 递增延迟 (staggered)
- 缓动函数：cubic-bezier(0.34,1.56,0.64,1) 弹性效果
- 内存状态：`state = 'expanded'`

### 状态 3：收起 (collapsed)
- 触发：再次点击主卡牌
- 4 张子卡牌滑回中心，opacity 渐变消失
- 主卡牌回到原位
- 状态回到 idle

### 状态 4：翻转详情 (detail)
- 触发：点击任一子卡牌
- 该子卡牌执行 3D 翻转动画：rotateY(180deg) 0.4s
- 翻转后放大至覆盖整个视口 (fixed inset)
- 显示该卡牌对应详情内容
- 右上角 × 关闭按钮
- 背景遮罩加深

### 状态 5：关闭详情
- 触发：点击 × 或点击遮罩外侧
- 详情层缩小翻转回正面
- 回到状态 2 (expanded)

## 卡牌规格

### 主卡牌
- 尺寸：280×360px
- 正面：深绿色调 + 标题 "Campus Life" + 副标题 "昭院生活指南"
- 背面：校徽水印 (`assets/校徽.PNG`) + 半透明遮罩
- 圆角：16px
- 阴影：0 12px 48px rgba(0,0,0,0.3)

### 子卡牌 × 4
- 尺寸：180×240px
- 正面：各自图标 + 标题 (宿舍🛏️/食堂🍜/运动⚽/商铺🛒)
- 背面：校徽水印，与主卡牌风格一致
- 圆角：14px
- 阴影比主卡牌小：0 8px 32px rgba(0,0,0,0.25)

### 翻转面
- 正面和背面都有 card-face 类
- CSS `backface-visibility: hidden` 实现双面
- `transform-style: preserve-3d` 容器

## 技术要点

- 纯 CSS 3D Transform + JavaScript 状态管理
- `perspective: 1000px` 在父容器
- 翻转：`transform: rotateY(180deg)`
- `backface-visibility: hidden` 隐藏背面
- 详情全屏：`position: fixed; inset: 0; z-index: 3000`
- 过渡动画：CSS transition 0.4s-0.6s
- 弹性缓动：`cubic-bezier(0.34,1.56,0.64,1)`
- 响应式：移动端主卡牌 200×280px、子卡牌 130×180px
